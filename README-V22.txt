CHOWNATUI V2.2

อัปเดตหลัก
- โลโก้ sidebar เป็น CHOWNATUI v.2.2 อยู่บรรทัดเดียวกัน
- ปรับ UI ตัวคั่น "ถึง" ของตัวเลือกช่วงวันที่ให้อยู่ระดับเดียวกับช่องวันที่
- ปรับช่อง วันที่ / ประเภท ในหน้าเช็คชื่อให้อยู่แนวเดียวกัน
- แก้หน้า "สมาตุ้ยทั้งหมด" ที่กดแล้วไม่แสดงเนื้อหา
- หน้าเวรทำความสะอาดให้สมาชิกทุกคนเปิดดูตารางเวรรวมได้
- ตารางเวรแสดงวันจันทร์–ศุกร์ของสัปดาห์ที่เลือก
- รองรับหลายชุดเวรในวันเดียว
- เพิ่มระบบแจ้งเตือนในเว็บเมื่อสมาชิกถูกเพิ่มเข้าเวรใหม่ พร้อมกระดิ่งแจ้งเตือน
